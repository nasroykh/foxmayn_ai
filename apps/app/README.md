# @repo/app

The web frontend: React 19, Vite 8, TanStack Router and Query, Tailwind CSS 4, Jotai.

## Entry points

- `src/main.tsx`: app bootstrap.
- `src/routes`: file-based routes. `_auth` routes need a session (chat, documents, profiles, credits, api-keys, settings, admin users, invite). `_notauth/auth` holds login, register and forgot-password.
- `src/routeTree.gen.ts`: generated by the router plugin. Do not edit.

## Key files

| Path | Purpose |
| --- | --- |
| `src/lib/orpc.ts` | Typed oRPC client and TanStack Query helpers. Types come from `@repo/api/orpc`. |
| `src/lib/auth.ts` | Better Auth client |
| `src/lib/api-url.ts` | API base URL (`VITE_API_URL`, default `/api/v1`) |
| `src/components/ui` | UI primitives |
| `src/components/admin`, `dashboard`, `settings`, `auth`, `layout` | Feature components |

## API access

The app always calls the API on its own origin. In development Vite (port 33460) proxies `/api` to `http://localhost:33450`. In production Caddy does it (`apps/app/Caddyfile`). There is no CORS setup to maintain.

## Commands

```bash
pnpm --filter @repo/app dev        # Vite dev server on 33460
pnpm --filter @repo/app build      # tsc -b && vite build
pnpm --filter @repo/app typecheck
pnpm --filter @repo/app lint
pnpm --filter @repo/app start      # vite preview
```

## Environment

`VITE_API_URL` (build time, default `/api/v1`). Read from the root `.env`. Leave it as is unless you also change the API prefix.

## Docker

`apps/app/Dockerfile` builds the SPA and serves it with Caddy. See [DOCKER.md](../../DOCKER.md).
